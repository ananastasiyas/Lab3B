# Справочник пользователей

## Запуск

Откройте `index.html` в браузере с доступом к интернету. Сервер и база данных не требуются.

## Реализовано

- Загрузка пользователей через GET (`fetch`, `async/await`) с JSONPlaceholder.
- Отображение имени, email и города в карточках.
- Поиск по имени без дополнительных запросов, независимо от регистра.
- Просмотр первых трёх публикаций выбранного пользователя через GET.
- Индикаторы загрузки, обработка HTTP- и сетевых ошибок, повторная попытка.

## Результаты проверок

- После загрузки список отображает 10 пользователей.
- Поиск `Leanne` оставляет подходящего пользователя; неизвестное имя выводит «Пользователи не найдены».
- По кнопке «Показать публикации» отображаются заголовки и тексты первых трёх публикаций.
- При ответе HTTP 404 выводится сообщение об ошибке; кнопка загрузки снова доступна для повторной попытки.
